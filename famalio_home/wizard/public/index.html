ZUGRIFF WÄHLEN

Wie soll die App den Server erreichen?

Tailscale

Empfohlen

Ein privates Netzwerk für Ihre Geräte. Für jedes Mobilgerät wird die Tailscale-App im selben Tailnet benötigt. Tailscale Serve stellt HTTPS bereit; der Assistent öffnet keine Router-Ports.

Vorhandenes HTTPS

Erweitert

Für eine bereits betriebene Domain und einen vorhandenen Reverse-Proxy mit öffentlich vertrauenswürdigem HTTPS-Zertifikat. Sie konfigurieren Proxy und DNS selbst.

Der Assistent richtet weder einen externen Router noch Ihren Reverse-Proxy ein. Verwenden Sie nur die bestehende, von außen erreichbare HTTPS-Adresse.

Bei Tailscale anmelden
Hinweise zur Reverse-Proxy-Konfiguration

Wenn Sie „Vorhandenes HTTPS“ wählen, leitet Ihr Reverse-Proxy zur vollständigen Famalio-API im internen Add-on-Netz weiter:

Wird nach Auswahl angezeigt

Der interne API-Upstream wird nach Auswahl von „Vorhandenes HTTPS“ angezeigt.

Der Upstream ist nur für den internen Netzwerkpfad zwischen Home Assistant und Add-on gedacht. Veröffentlichen Sie Port 8787 nicht direkt im LAN oder Internet. DNS, öffentliche HTTPS-Zertifikate und den externen Proxy richten Sie selbst ein.

Prüfen Sie anschließend hier die Origin und Serveridentität.

Wenn Sie DNS, gültiges HTTPS oder Proxy-Regeln erst einrichten müssen, wählen Sie zunächst Tailscale oder richten Sie diese Infrastruktur außerhalb dieses Assistenten ein.

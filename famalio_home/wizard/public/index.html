Home Assistant muss einmal neu starten

Famalio hat seinen Teil für Home Assistant installiert. Damit er benutzt werden kann, muss Home Assistant neu starten. Das dauert etwa ein bis zwei Minuten. Danach geht es hier von selbst weiter.

1

Schritt 1: Zugang einrichten

Damit dein Handy deinen Famalio-Server auch unterwegs sicher erreicht, brauchen wir einen privaten Zugang. Dafür nutzen wir Tailscale (kostenlos). Tippe einfach auf den Knopf.

Bei Tailscale anmelden

Wenn sich ein neues Fenster öffnet: Melde dich bei Tailscale an (ein Konto ist kostenlos) und komm danach hierher zurück. Diese Seite geht von selbst weiter.

Erweitert: eigene HTTPS-Adresse verwenden

Nur für Fortgeschrittene: Du betreibst schon eine Domain mit Reverse-Proxy und gültigem HTTPS-Zertifikat. Dann gib hier die Adresse ein. Sonst bleib bei „Zugang einrichten“.

Der Assistent richtet weder Router noch Reverse-Proxy ein. Leite den Proxy auf den unter „Technische Details“ gezeigten internen Upstream.

2

Schritt 2: Famalio-App verbinden

Warte auf Schritt 1.

ADRESSE DEINES SERVERS
–
EINRICHTUNGSCODE (EINMALIG GÜLTIG)
–

Der Einrichtungscode ist abgelaufen. Starte das Famalio-Add-on unter „Technische Details → Add-on verwalten“ einmal neu, dann erscheint hier ein neuer Code.

In der Famalio-App öffnen

Am Handy: Tippe auf den Knopf. Die App füllt Adresse und Code aus, du bestätigst mit „Home-Familie erstellen“.

  1. Öffne die Famalio-App auf deinem Handy.
  2. Tippe auf Einstellungen → Famalio Home → Home-Server verbinden.
  3. Tippe auf Einrichtungscode scannen und halte die Kamera auf den QR-Code. Oder tippe Adresse und Code von Hand ein.
  4. Tippe auf Home-Familie erstellen und speichere den angezeigten Wiederherstellungscode gut.

3

Schritt 3: Home Assistant verbinden

Tippe auf den Knopf. Du bekommst einen Code, den du in der Famalio-App bestätigst. Mehr ist nicht nötig.

DEIN VERBINDUNGSCODE ····-····
  1. Öffne die Famalio-App.
  2. Tippe auf Einstellungen → Famalio Home → Home-Server verbinden → Verbindungsanfragen.
  3. Prüfe, dass dort derselbe Code steht, und tippe auf Verbindung erlauben.
  1. Anfrage senden
  2. In der App bestätigen
  3. Verbunden
Erweitert: mit Integrationstoken verbinden

Der Token wird nur für diese Anfrage verwendet und danach aus dem Feld entfernt.
